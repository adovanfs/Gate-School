## ✨ Tentang

**Gate School** adalah sekolah prompting AI **gratis** yang dibuat untuk siapa aja — pelajar, profesional, content creator, atau cuma penasaran.

Kami percaya **masa depan bukan cuma buat yang bisa ngoding**. Bisa berbicara dengan AI secara efektif adalah skill baru yang wajib dikuasai semua orang.

> Karena AI itu kayak asisten super pinter — tapi dia **gak bisa baca pikiranmu** dan **lupa segalanya tiap kali kamu tinggalkan ruangan**. Tugasmu: jelasin dengan jelas.

## 📚 Kurikulum

### Level 01 — Pemula
> Kenalan sama AI, pahami cara kerjanya, dan tulis prompt pertamamu.

- Apa Itu AI & LLM?
- Anatomi Prompt
- Prompt Pertamamu
- Kesalahan Umum Pemula
- Berpikir Seperti AI

### Level 02 — Menengah
> Few-shot, chain of thought, role prompting — senjata dasar.

- Zero, One, Few-Shot
- Chain of Thought
- Role Prompting
- Format Output
- Konteks adalah Raja
- Iterasi Prompt

### Level 03 — Advanced
> ReAct, self-consistency, tree of thoughts, prompt chaining.

- ReAct: Reasoning + Acting
- Self-Consistency
- Tree of Thoughts
- Prompt Chaining
- Meta-Prompting
- Task Decomposition

### Level 04 — Expert
> System prompt, persona, structured output, RAG, evaluasi.

- System Prompt Engineering
- Membangun Persona & Agent
- Structured Output (JSON)
- Function Calling & Tools
- RAG & Context Engineering
- Evaluasi Prompt (A/B)
- Prompt Library Pribadi

### Level 05 — Master
> Automation, multi-agent, security, dan produksi skala besar.

- Prompt untuk Automation
- Multi-Agent Systems
- Security & Prompt Injection
- Cost Optimization
- Memilih Model yang Tepat
- Shipping ke Produksi

**Total: 5 level · 28+ pelajaran · 2 bahasa**
